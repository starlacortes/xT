# xT App - User Experience Flow Diagram

## Overview

This document describes the complete user experience flow for the xT health tracking application, organized into development phases. The app helps users track hormone replacement therapy (HRT) medication, journal their experiences, and visualize their progress over time.

---

### 3.2 Home View Interactions

```
┌─────────────────────────────────────────────────────────────────┐
│ HOME VIEW INTERACTIONS                                          │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ GRAPH TAP                                                       │
│ ───────────                                                     │
│ Action: User taps on FlatGraphView                             │
│ Result: Opens GraphView sheet with detailed hormone graph      │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ RECORD DOSE BUTTON                                              │
│ ───────────────────                                             │
│ Action: User taps "Record dose" in Quick Actions               │
│ Flow:                                                           │
│   1. MedicationManager.recordDose(on: Date())                  │
│   2. Shows confirmation alert: "Dose recorded"                 │
│   3. Updates UI with new dose data                             │
│   4. Refreshes graph and insights                              │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ SCHEDULE BUTTON                                                 │
│ ─────────────────                                               │
│ Action: User taps "Schedule" in Quick Actions                  │
│ Result: Navigates to UnifiedScheduleView                       │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ JOURNAL NEW ENTRY                                               │
│ ────────────────────                                            │
│ Action: User taps "new entry…" or compose icon                 │
│ Result: Opens JournalComposerView sheet                        │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ MISSED DOSE PROMPT                                              │
│ ────────────────────                                            │
│ Trigger: MedicationManager.hasMissedDose == true               │
│ Action: User taps "Record Dose"                                │
│ Result: Records dose and dismisses prompt                      │
└─────────────────────────────────────────────────────────────────┘
```
