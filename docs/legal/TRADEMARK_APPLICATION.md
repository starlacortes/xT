# Isocline — US Trademark Application Worksheet

Prepared for Starla Cortes. Draft only — not legal advice. Have a trademark
attorney review before filing (your own market-positioning paper requires this,
and it is cheap insurance for a word mark you intend to own for years).

## Scope of this application

- **Mark:** `ISOCLINE` (standard character / word mark, no logo or stylization)
- **Classes:** 9 only (downloadable software)
- **Basis:** §1(b) — bona fide intention to use in commerce (not yet used)
- **Filing system:** TEAS Plus (cheapest path; this application qualifies)

---

## 0. Do these BEFORE filing (in order)

1. **Form the Ohio LLC.** The applicant must be the entity that owns and will
   use the mark. You cannot file in the name of an LLC that does not exist yet.
   Ohio SOS filing is ~$99, same-day online.
2. **Get the LLC's EIN** from the IRS (free, online, instant). You will not need
   it on the trademark form itself, but you need the entity to be real and
   named correctly.
3. **Decide the LLC's exact registered name.** This exact string goes in the
   "Owner of Mark" field. Do not guess or abbreviate. Example choices and how
   they interact with the mark:
   - `Isocline Labs LLC` — cleanest brand-to-entity match.
   - `Isocline Research LLC` — matches the paper's "Isocline Research" arm idea,
     but reads more nonprofit-adjacent than a subscription app wants.
   - A neutral name (`Cortes Software LLC`) also works; the entity name does not
     have to contain the mark.
4. **Have a trademark attorney run a real clearance search** in class 9 (and
   ideally 42/44 as a courtesy) before anything is filed or printed. The
   Justia-only screen in `market-positioning-paper` found nothing in class 9,
   but it is explicitly *not* clearance.

## 3. Goods and services — Class 9

TEAS Plus requires the identification to be drawn from (or closely track) the
USPTO ID Manual. Use this wording; it is a functional, non-medical description
that stays on the correct side of the "device vs. model" claim boundary your
paper documents:

> **Class 9:** Downloadable computer application software for mobile devices
> and tablet computers, namely, software for tracking hormone replacement
> therapy injections and dosing schedules, generating medication reminders,
> and modeling predicted hormone levels over time.

Alternate, more conservative ID (use if you want to minimize examiner
pushback on "hormone replacement therapy"):

> **Class 9:** Downloadable software in the nature of a mobile application for
> tracking medication injections, scheduling medication reminders, and
> generating predictions of medication levels over time.

What this application does **not** cover (do not add these here):
- **Class 42** — hosted/cloud software services (SaaS), data analytics. Add this
  only if you later ship a web service or a data/analytics offering.
- **Class 44** — medical/health services. A self-tracking app is **not** a
  medical service. Adding class 44 now would be rejected or invite an
  "inaccurate identification" objection. Only pursue it if you later add
  telehealth or provider-facing services.

## 4. Filing basis — §1(b)

- **Basis:** "The applicant has a bona fide intention to use or use through the
  applicant's related company or licensee the mark in commerce on or in
  connection with the identified goods and/or services."
- **No specimen required now.** You will need a specimen (App Store listing
  screenshot showing the name + a download/purchase flow) when you file the
  Statement of Use.
- **Deadlines:** once the mark is allowed (Notice of Allowance), you have
  **6 months** to file a Statement of Use (§1(a)) or an extension request
  (§1(d)). Extensions are available in 6-month increments up to a total of
  **~3 years** (five extension requests). You do not need to launch the app
  just to keep the application alive — but each extension costs a filing fee.

## 7. Post-filing timeline (what to expect)

1. **~2–4 weeks:** USPTO assigns a serial number and reviews for formality.
2. **~8–12 months:** substantive examination. Expect possibly an Office Action
   asking to refine the goods description; respond within the deadline.
3. **Publication:** the mark is published for opposition (~30 days).
4. **Notice of Allowance:** if §1(b), the 6-month statement-of-use clock starts.
5. **Statement of Use + specimen** once the app is live under the name.
6. **Registration** (~1 year after filing, give or take).
