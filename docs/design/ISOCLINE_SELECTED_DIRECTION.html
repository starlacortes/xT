Paper & Instrument

I+III

Halleyan paper, isoclinic instrument

one seed hue · every color derived

I keeps the first isoline charts' grammar — hairline weights, values written along the line, the double rule where the compass stands true — but the parchment is no longer a static cream: it is the app's own ground recipe with its chroma lifted, so the paper is warm at every position of the dial. III keeps the dip circle — horizontal zero, graduated arc, the needle settling to today's reading — but the needle now wears levelTint, the app's rose→lavender ramp, because in this system the level's color is its meaning.

Kept from I · the paper

  • Seed-tinted paper ground — recipe, not hex; rose-blush at default, sage at Steady.
  • Hairline grid at the app's own gridLine opacities — more lines, never louder.
  • Value along the line — the plateau carries its number, at secondary weight: it is a modeled number.
  • Double rule for steady — Halley's "stands true" mark under the plateau.
  • Plate framing on the landing hero, double-ruled.

Kept from III · the instrument

  • The dip circle — zero-dip reference, graduated quarter-arc, needle reading today.
  • Ghost swings — the settle, drawn as fading oscillation.
  • Strict scope — an arc only ever means a level reading; never nav, never cards.

Reconciled to the system

  • Today's marker follows the app's levelTint, not fixed rose — level color = level meaning.
  • Needle = levelTint; pivot = accent; arc and ticks = ink.
  • Trough band stays green — semantic colors are deliberately non-theme in the app.
  • Curve stroke 1.8pt, right-edge y labels, dose dots — FlatGraphView's actual furniture.
  • Slope field reserved to the landing hero; the app chart stays quiet.

Method

Color derivation mirrors ThemeManager.resolve: every token is an OKLCH recipe (lightness, chroma, hue offset from the seed) computed from the values in the app's recipe table — accent L .6225/C .1666, ink L .10/.94, levelLow −1.95°, levelHigh +288.42°, and so on — gamut-clamped by bisection like ThemeEngine.clampToGamut. The default seed is computed from #D4537E exactly as ThemeManager.defaultSeedHue does. The app's WCAG repairContrast pass is noted, not simulated. Curves are the same in-page Bateman superposition as the direction board: ka 1.2 d⁻¹, ke = ln2/8.5 d⁻¹, scaled so the day-10 draw reads 180 pg/mL; today's readout is whatever the math says. Trough band 100–200 pg/mL per the documented E2 reference ranges.
