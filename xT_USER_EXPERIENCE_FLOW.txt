xT App - User Experience Flow (Plain Text)
=============================================

PHASE 1: APP LAUNCH
--------------------
- App launches
  -> xTApp initializes
    -> Creates ModelContainer (SwiftData schema)
    -> Sets up managers (Medication, Journal, Notification, Profile, Auth)
    -> Configures notification categories & schedules reminders
  -> ContentView loads
    -> Checks hasCompletedOnboarding (AppStorage)
    -> Checks auth requirements
  -> Branch: First launch vs Returning user
    -> First launch: Shows OnboardingView (4 steps)
    -> Returning user: Shows MainTabView (4 tabs)
    -> Quick check: If medication data exists but onboarding flag is false
       -> Auto-completes onboarding and proceeds to MainTabView


PHASE 2: ONBOARDING FLOW (4 STEPS)
-----------------------------------
STEP 1: WELCOME
- Displays xT logo and "Welcome to your journey" text
- Shows "Begin" button with gradient background
- User taps "Begin"
  -> Fade-out animation (0.3s)
  -> Advances to Step 2 with fade-in animation

STEP 2: FEATURES OVERVIEW
- Shows 3 feature rows with icons:
  -> Pill icon: "Track your medication"
  -> Chart icon: "Understand your levels"
  -> Heart icon: "Feel supported"
- Shows "Back" and "Continue" buttons
- User taps "Continue"
  -> Advances to Step 3

STEP 3: PROFILE SETUP (OPTIONAL)
- Shows "This is your space" heading
- Displays circular photo placeholder (tap to add photo)
  -> Opens PhotosPicker (images only)
  -> Opens CameraPicker (camera capture)
  -> profileManager handles photo selection and storage
- Text field for profile name (optional)
- Two buttons: Photo Library / Camera
- Shows "Back" and "Continue" buttons
- User taps "Continue"
  -> Saves profile name if provided
  -> Advances to Step 4

STEP 4: MEDICATION SETUP
- Shows "Let's set up your tracking" heading
- Medication Type selection:
  -> Estrogen (default first)
  -> Testosterone
  -> On selection: Auto-selects first available method
  -> On selection: Resets dose to typical range (2.0 mg for estrogen, 40.0 mg for testosterone)
- Administration Method selection (filtered by type):
  -> Injectable
  -> Patch
  -> Gel
  -> On select: If NOT injectable, resets ester selection
- Ester selection (shown only if Injectable):
  -> Valerate
  -> Cypionate
  -> Other esters based on medication type
- Dose Amount:
  -> Stepper control (0.5 to 500, step 0.5)
  -> Text field with decimal keyboard
  -> Quick-select common dose buttons (horizontal scroll)
    -> Estrogen: 0.5, 1, 2, 4, 6
    -> Testosterone: 20, 40, 60, 80, 100
- HRT History:
  -> "Just starting" button
  -> "I've been on it" button
  -> If "been on it": Shows duration picker
    -> Time unit: Month / Year (segmented control)
    -> Stepper: 1-23 (months) or 1-10 (years)
- "Back" and "You're all set" buttons
- User taps "You're all set":
  -> Records first dose with selected parameters
  -> Sets medicationManager.selectedMedication
  -> Sets medicationManager.selectedAdministrationMethod
  -> Sets hrtStartDate (if applicable)
  -> Sets hasCompletedOnboarding = true
  -> Fade-out animation
  -> Navigates to MainTabView


PHASE 3: MAIN TAB NAVIGATION
-----------------------------
- TabView with 4 tabs:
  -> Tab 0 (House icon): HomeView
  -> Tab 1 (Book icon): JournalView
  -> Tab 2 (Sparkle icon): BloomView ("Time")
  -> Tab 3 (Gear icon): SettingsView
- Tab tint: Theme.Colors.accent
- fullScreenCover overlay: AuthenticationView (when auth required)


PHASE 4: HOME TAB
------------------
Structure (top to bottom in ScrollView):
- HeroView
  -> Profile greeting
  -> Current hormone level
  -> Cycle day indicator
- FlatGraphView (only if medication is configured)
  -> Hormone level trend visualization
  -> Tap -> Opens GraphView sheet (full screen)
- MainContentView
  -> MissedDosePrompt (if hasMissedDose == true, always first)
  -> FlatQuickActionsRow
  -> FlatInsightRow (if configured)
  -> JournalHomeRow
  -> FlatNextDoseRow (if configured)

INTERACTIONS:

Graph Tap:
- User taps FlatGraphView
  -> Opens GraphView as a sheet

Record Dose (Quick Actions):
- User taps "Record dose" button
  -> MedicationManager.recordDose(on: Date())
  -> Shows alert: "Dose recorded" with "OK" button
  -> UI updates with new dose data

Schedule (Quick Actions):
- User taps "Schedule" button
  -> Navigates to UnifiedScheduleView

Journal New Entry:
- User taps "new entry..." or pencil icon
  -> Opens JournalComposerView as a sheet
  -> Shows today's entry preview if exists
  -> 80:20 split layout: preview left, compose right

Missed Dose Prompt:
- Appears when hasMissedDose == true
- Shows message about missed dose
- "Record Dose" button -> records dose immediately
- Dismissible
- Auto-hides after recording


PHASE 5: JOURNAL TAB
---------------------
Structure:
- Journal hero header ("Journal" in large gradient text, entry count)
- TimelineScrubber (horizontal scroll, date pills)
  -> "Today", "Yesterday", weekday names, or "Mon X" format
  -> Tap -> scrolls to that date's group
- Entry list (grouped by date, most recent first)
  -> Date headers in uppercase
  -> Each entry shows: color dot, preview text, mood + first symptom, time
  -> Tap entry -> Opens JournalDetailSheet
- Floating "+" button (bottom right, 56x56 circle)
  -> Opens JournalComposerView

INTERACTIONS:

Create New Entry:
- User taps "+" button or "new entry..."
  -> Opens JournalComposerView (full screen sheet)
  -> Layout:
    -> Status bar mock (top)
    -> Navigation: [Cancel] "New entry" [Save]
    -> Mood selector (horizontal scroll): Happy, Neutral, Sad, Angry, Anxious
    -> Text entry (TextEditor with placeholder "Write how you're feeling...")
    -> Symptoms selector (FlowLayout of toggle tags)
    -> Hormone insight card (if configured)
  -> Save:
    -> Creates JournalEntry with current date, mood, text, symptoms
    -> Adds to JournalManager
    -> Dismisses sheet

Journal Detail Sheet:
- Opens when tapping an entry
- Shows full entry text
- Shows mood, all symptoms, timestamp
- Edit/Delete options


PHASE 6: TIME (BLOOM) TAB
--------------------------
Structure (top to bottom in ScrollView):
- BloomHeroHeader
  -> Timeline subtitle ("Month 3 · Week 2")
  -> Timeline title in gradient ("Transformation in Progress")
  -> Medication + method ("Estrogen · Injectable")
- BloomHormoneRow (if hormone insight exists)
  -> "HORMONE LEVELS" label + range badge
  -> Animated counter with value and unit
  -> Body description text
- BloomChangesRow
  -> "CHANGES UNLOCKED" count ("3 of 12")
  -> Horizontal scroll of change badges
    -> Checkmark icon (unlocked) vs Clock icon (locked)
    -> Green accent (unlocked) vs Gray (locked)
- BloomBodySection
  -> "YOUR BODY" header
  -> List of body systems with progress:
    -> Icon + title + progress percentage
    -> Subtitle with description
    -> Progress bar (animated on appear)
    -> Brain, Skin, Body Composition, etc.
- BloomMilestonesSection
  -> "COMING UP" header
  -> List of upcoming milestones:
    -> Icon + title + badge (timeframe)
    -> Description text
    -> Clock icon, flask icon, star icon

Cycle Day Calculation:
- Uses lastDoseDate and administration frequency
- cycleDay = (elapsedDays % frequencyDays) + 1


PHASE 7: SETTINGS TAB
----------------------
Structure (top to bottom in ScrollView):
- Profile Header Block
  -> 120x120 circular profile photo (or gradient circle placeholder)
  -> Profile name in large gradient text (if no photo)
  -> "Edit Profile" navigation link -> ProfileEditorView
  -> Stats strip (if configured):
    -> Level string (e.g., "150 pg/mL")
    -> Next dose string ("Today" / "Tomorrow" / "In Xd")
    -> Months on HRT ("3 mo")
- Medication Section
  -> "Type & method" row -> UnifiedScheduleView
  -> "Dose schedule" row -> UnifiedScheduleView
  -> "Record a dose" button -> MedicationManager.recordDose()
- Notifications Section
  -> Dose reminders toggle + time row
  -> Journal reminders toggle + time row
- Privacy & Security Section
  -> "App lock" row -> AppLockSettingsView
  -> Shows biometric type + timeout label
- About Section
  -> "Version 1.0.0"
  -> "Reset app data" (destructive button)

INTERACTIONS:

Edit Profile:
- Taps "Edit Profile"
  -> Navigates to ProfileEditorView
  -> Change photo / Edit name

Type & Method / Dose Schedule:
- Taps either row
  -> Navigates to UnifiedScheduleView(isFromSettings: true)

Record Dose:
- Taps "Record a dose"
  -> MedicationManager.recordDose(on: Date())
  -> Dose logged with current date

Dose Reminder Toggle:
- Taps toggle switch
  -> Updates UserDefaults "doseReminderEnabled"
  -> Calls NotificationManager.configureDoseReminder()
  -> Schedules or cancels daily notification
- Taps time row (when enabled)
  -> Opens TimePickerSheet
  -> Selects hour and minute
  -> Updates reminder schedule

Journal Reminder Toggle:
- Same flow as dose reminder
  -> Updates UserDefaults "journalReminderEnabled"
  -> Calls NotificationManager.configureJournalReminder()

App Lock:
- Taps "App lock" row
  -> Navigates to AppLockSettingsView
  -> Enable/disable lock
  -> Set timeout (Immediately, 1min, 5min, 15min, 30min, 1hr)
  -> Toggle passcode fallback

Reset App Data:
- Taps "Reset app data"
  -> Shows confirmation alert
  -> If confirmed:
    -> Clears all UserDefaults keys
    -> Clears profile image
    -> Clears profile name
    -> Clears medication selection
    -> Clears SwiftData (JournalEntry)
    -> Sets hasCompletedOnboarding = false
  -> App returns to onboarding state


PHASE 8: AUTHENTICATION & SECURITY
------------------------------------
TRIGGER CONDITIONS:
- App background -> foreground (when locked)
- Timeout expiration (default 5 min inactivity)
- Fresh install with requireAuthentication = true
- Manual lock via settings

AUTHENTICATION VIEW:
- Gradient background (Theme.Gradients.brand)
- Biometric icon (Face ID / Touch ID / Lock)
- "Authenticate to continue" heading
- "Access your health data" subtitle
- Error message display (if authentication fails)
- Loading spinner during authentication
- "Authenticate with [BiometricType]" button
  -> Auto-triggers on appear via .task modifier
- "Use passcode instead" link (if biometric unavailable or failed)
- interactiveDismissDisabled(true) - cannot bypass

AUTHENTICATION METHODS:
- Face ID (primary, if device supports)
- Touch ID (primary, if device supports)
- Optic ID (primary, if device supports)
- Device Passcode (fallback via .deviceOwnerAuthentication policy)

SCENE PHASE HANDLING:
- .background: isAuthenticated = false, hasExited = true (no view shown yet)
- .active: If requireAuthentication && hasExited -> show AuthenticationView
- .inactive: No action (prevents locking on Control Center/Notification Center pulls)

ACTIVITY TRACKING:
- AuthenticationManager.lastActivityTime updates on successful auth
- recordActivity() called by AuthenticationRequiredModifier.onAppear
- Timeout comparison: Date() - lastActivityTime > autoLockTimeout


PHASE 9: NOTIFICATION SYSTEM
-----------------------------
NOTIFICATION CATEGORIES:
- Dose Reminders (category: "dose_reminder")
  -> Daily at configured time
  -> Action: "Record Dose"
- Journal Reminders (category: "journal_reminder")
  -> Daily at configured time
  -> Optional (disabled by default)
  -> Action: "Write Entry"

SETUP FLOW:
App Launch:
- NotificationManager.setupNotificationCategories()
- NotificationManager.requestAuthorization()
- NotificationManager.scheduleAllReminders()

User Enables Reminder:
- Toggle in SettingsView
- onDoseReminderToggle(newValue) / onJournalReminderToggle(newValue)
- Calls configureDoseReminder(enabled, hour, minute) / configureJournalReminder()
- Schedules UNNotificationRequest with fireDate

User Changes Time:
- Opens TimePickerSheet
- onDoseTimeChange() / onJournalTimeChange()
- Cancels old notifications, schedules new ones

Authorization:
- Requested on settings appear
- Uses UNUserNotificationCenter.requestAuthorization(options: [.alert, .badge, .sound])


PHASE 10: DATA MANAGEMENT
--------------------------
MANAGERS (Singleton pattern, injected via environment):

MedicationManager:
- selectedMedication (String: "Estrogen" or "Testosterone")
- selectedAdministrationMethod (String: "Injectable", "Patch", "Gel")
- selectedEster (String: "Valerate", "Cypionate", etc.)
- doseAmount (Double)
- hrtStartDate (Date?, computed from hasBeenOnHRT duration)
- doseRecords (SwiftData: [DoseRecord])
- Computed properties:
  -> isFullyConfigured: all fields set
  -> isPartiallyConfigured: some fields set
  -> nextDoseDate: lastDoseDate + frequencyDays
  -> lastDoseDate: max(doseRecords.date)
  -> hasMissedDose: nextDoseDate < now (and dose not recorded)
  -> currentHormoneLevel: estimated from dose + time since last dose
  -> monthsOnHRT: time from hrtStartDate to now
- Methods:
  -> recordDose(on: Date) -> adds DoseRecord
  -> addDose(date, type, ester, method, doseAmount)
  -> calculateNextDoseDate(from: Date) -> Date
  -> availableMethods(for: MedicationType) -> [AdministrationMethod]
  -> getConfigurationSummary() -> String
  -> getMedicationDisplayInfo() -> String
  -> clearSelection()

JournalManager:
- entries (SwiftData: [JournalEntry])
- modelContext (injected)
- Computed:
  -> lastEntry: entries.max(by: { $0.date < $1.date })
- Methods:
  -> addEntry(_ entry: JournalEntry)
  -> deleteEntry(_ entry: JournalEntry)
  -> loadEntries() -> fetched results from SwiftData

ProfileManager:
- profileName (AppStorage: "profileName")
- profileImage (UIImage?, stored in FileManager)
- profileImageData (Data?, AppStorage: "profileImageData")
- selectedPhotoItem (PhotosPickerItem?)
- Computed:
  -> profileDisplayName: profileName if non-empty, else "Guest"
  -> hasProfileData: name or image exists
- Methods:
  -> updateProfileName(_ name: String)
  -> handlePhotoSelection()
  -> getCurrentProfileImage() -> UIImage
  -> clearProfileImage()

NotificationManager:
- modelContext (injected)
- Methods:
  -> setupNotificationCategories() -> creates UNNotificationCategory
  -> requestAuthorization() -> async, requests permissions
  -> configureDoseReminder(enabled, hour, minute) -> schedules/cancels
  -> configureJournalReminder(enabled, hour, minute) -> schedules/cancels
  -> scheduleAllReminders() -> reschedules all enabled reminders
  -> scheduleDailyReminder(for: category, hour, minute) -> UNNotificationRequest
  -> cancelAllReminders() -> removes pending notifications

AuthenticationManager:
- requireAuthentication (AppStorage: "requireAuthentication")
- autoLockTimeout (AppStorage: "autoLockTimeout")
- isAuthenticated (Published: Bool)
- showAuthentication (Published: Bool)
- lastActivityTime (Published: Date)
- hasExited (private: Bool)
- Methods:
  -> authenticate() -> async throws (biometric)
  -> authenticateWithPasscode() -> async throws (device passcode)
  -> recordActivity() -> updates lastActivityTime
  -> handleScenePhase(_ phase) -> background/active transitions
  -> biometricType() -> BiometricType (.none, .touchID, .faceID, .opticID)
  -> canUseBiometrics() -> Bool

SecurityManager:
- Coordinates with AuthenticationManager
- Enforces app lock on sensitive actions

DATA PERSISTENCE:
SwiftData Models:
- UserPreferences
- DoseRecord
- JournalEntry
- JournalEntrySymptom (relationship)

UserDefaults Keys:
- selectedMedication
- selectedAdministrationMethod
- selectedEster
- doseReminderEnabled / doseReminderHour / doseReminderMinute
- journalReminderEnabled / journalReminderHour / journalReminderMinute
- hasCompletedOnboarding
- requireAuthentication / autoLockTimeout / allowPasscodeFallback
- profileName
- profileImageData

USER JOURNEY MAP
================

FIRST TIME USER:
1. Download & Launch
     -> OnboardingView loads (4 steps)
2. Step 1: Welcome -> taps "Begin"
3. Step 2: Features overview -> taps "Continue"
4. Step 3: Profile setup (optional) -> enters name/photo or skips
5. Step 4: Medication setup
   -> Selects Estrogen/Testosterone
   -> Selects method (Injectable/Patch/Gel)
   -> Selects ester (if injectable)
   -> Enters dose amount (or uses quick-select)
   -> Indicates HRT history (just starting / been on it)
   -> Taps "You're all set"
     -> First dose recorded
     -> hasCompletedOnboarding = true
     -> Navigates to MainTabView (Home tab)
6. Home tab: Sees personalized greeting, graph (if data), quick actions
7. Explore tabs: Journal, Time, Settings
8. First journal entry: Taps "+" -> selects mood, writes text, selects symptoms
9. First dose record: Taps "Record dose" or uses Settings


RETURNING USER:
1. Launch app
     -> Content View checks hasCompletedOnboarding -> true
     -> MainTabView loads
     -> If auth required -> AuthenticationView shows
2. Authentication (if enabled)
   -> Face ID / Touch ID automatic prompt
   -> Fallback to passcode if needed
   -> On success: isAuthenticated = true
3. Home tab (default)
   -> See hormone levels, graph
   -> Record dose from Quick Actions
   -> Check missed dose alerts
4. Navigate between tabs freely
5. Daily interactions:
   -> Record doses
   -> Write journal entries
   -> Check bloom progress


POWER USER FEATURES:
- UnifiedScheduleView: Detailed schedule management, past dose recording
- Journal timeline: Browse historical entries, filter by date
- Bloom tab: Track body changes, milestone progress
- Notification customization: Enable/disable, change times
- App lock: Configure timeout, biometric preference, passcode fallback
- Data reset: Clear all data and restart onboarding
